# Student Result Management System

Core Java console-based Student Result Management System.

## Features
- Teacher and Student menus
- Student registration with unique roll numbers
- Five-subject marks entry/update
- Total, average, PASS/FAIL calculation
- ArrayList and HashSet usage
- Text-file persistence
- Class reports
- Input validation

## Project Structure
- User.java
- Teacher.java
- Student.java
- ResultService.java
- FileManager.java
- Main.java
